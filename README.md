## 👨‍✈️ About me

I build **safety-critical avionics software** — the kind that has to work every single time. My work spans the whole DO-178C lifecycle: requirements, design, code, verification, and the plans and standards that hold them together.

- 🛩️ **Now:** Senior Avionics Software Design Engineer at [ESEN System](https://esensi.com.tr/), developing **DO-178C DAL A** software for VOR/ILS navigation receivers (C99 · MISRA C · Xilinx Zynq · ARINC 429 · MIL-STD-1553).
- 🧪 Building **test automation infrastructure** and internal tooling: a TQL-5 qualified tool, Qt/C++ and Python utilities, Jenkins quality gates, Grafana/Prometheus metrics, and an AI-assisted VS Code extension for test scripts.
- 🎓 **MSc** in Computer Software Engineering (Hacettepe University) · **BSc** in Electrical & Electronics Engineering (IzTech) · now pursuing a **second master's in Systems Engineering**.
- 📜 **INCOSE CSEP** · **ISTQB CTAL-TAE** · ISTQB CTFL
- 📖 Writing an open, community-driven **Turkish book on avionics software** at [aviyonikyazilim.com](https://www.aviyonikyazilim.com/).
- 🌍 Wikimedia technical volunteer since 2014 ([225k+ edits](https://tr.wikipedia.org/wiki/Kullan%C4%B1c%C4%B1:Mavrikant)) and co-founder of **Dijital Bilgi Derneği**.
- 💬 Ask me about **DO-178C, requirements engineering, MISRA C, test automation or systems engineering**. Happy to help!
